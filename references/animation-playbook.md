# 动画、插画与镜头合成实作

在 `full-variety` 制作、效果对照或用户指出“像相册、缺动画/插画”时，与 variety-effects、variety-openings 和 production-pipeline 配合使用。这里规定可见动作、实际资产、工程接口和检查方法；具体画风、物件与参数按本片设计。

## 先判断缺的是哪一层

| 现象 | 需要补的工作 | 不能算修复 |
|---|---|---|
| 风景轮播、照片卡与短句反复出现 | 重新组织观察/行动，加入内容相关的分层场景与动作交接 | 再加几条描边字、换卡片颜色 |
| 插画只在角落静止 | 设计插画的行为、状态变化和与主体的接触关系 | 放大角标、堆 emoji |
| 所有层都滑入或弹入 | 分配不同动作：路径、形变、遮挡、展开、碰撞、擦除 | 为同一入场改十个 easing 名称 |
| “三维感”只有整张照片推近 | 分离前中后景，补足遮挡区域，给不同景深设置运动与相机 | 所有层等速平移 |
| 圆形放大窗反复出现 | 按信息用途选择轮廓描摹、物件提取、局部接管画面或同形接镜 | 仅改变圆窗大小和位置 |
| 动画很多却不像综艺 | 修复铺垫、视觉重音、反应与声音的时序 | 用关键帧数、图层数、切镜数证明质量 |

照片、Live Photo、实拍视频分别判断。没有真人互动可以做景物、食物、交通与手绘物件的动态旅行拼贴；不把缺真人当成只能做静态卡片的理由，也不编造真实对白、比赛与反应。单张照片的分层视差有视角上限，不能许诺绕物摄影或不存在的遮挡后内容。

## 画风按段落用途选择

下列是可复用的视觉语言，不是全片必须串齐的模板：

- **生活观察与视觉错觉**：用真实物件、影子、路牌、窗、镜面与前景做同形或遮挡交接；必要时采用局部替换、画中画、可解释的合成。实拍本身有信息时保持干净，不强塞满屏漫画包装。
- **人物旅行综艺**：用原创人物剪贴/头像、表情动作、短花字、路线进展和阶段反馈，把人物与地点联系起来。图形先有行为，再有装饰。
- **插画主题舞台**：将地标、环境、交通、食物或人物拆成可动构件，形成可读空间，通过场景内物件进入实拍。不能仅在纯色底摆几张带框照片。
- **短促章节或看点单元**：文字、插画载具、撕纸/布景等串成一段有开端、发展和落点的动作。教程中的占位词、模板提示不进入交付画面。

整片共用线条、颜色语义与字体；不同语言可以按主线切换，交接要有视觉或声音依据。画幅和时长分别设计，不把数分钟片头按比例直接搬进一分钟影片。

### 手帖式剪贴舞台与动态地图

适用于路线、城市漫游、站点集锦和需要较强图像化识别的旅行段落。它是可选的构图语言，不是固定模板：建立铺满画面的环境底图，再把真实地标、交通、食物、人物或装备制作成独立剪贴层；用同一条路线、共同基线或前景遮挡连接元素。纸边、缝线、邮戳和像素符号只在它们解释材质、路线或情绪时出现，不要随机贴满画面。

动画至少有一条明确的动作链：路线被绘出，行进物件沿线到站，站点地标受力/展开，标题跟着落位，最终由场景元素擦开并把观众带进真实素材。各层需要不同运动职责和前后关系；例如环境慢速视差、路线按路径绘制、交通物件沿路径行进、地标由遮罩揭示、标题在揭示后停留。它们不能只是在不同方向弹入。

美术需按本片目的地和素材定制：复杂地标采用用户素材提取或专门绘制/生成的透明图层；SVG/CSS 适合路线、标签、标记、基础云形和版式装饰，不能把几个几何山形和一座抽象塔当作寺院、古城或悬崖等具体景观的插画。照片比例与目标画幅不匹配时，重新排构图或有意裁切；避免自动复制照片、强模糊、压暗后当作默认填充。

同一作品可在章节间切换水彩、蜡笔、像素或摄影剪贴等媒材，但每段必须有完整峰值构图和稳定的文字/边缘规范；切换应由地点、内容或情绪推动。把路线、云、车或角色作为可选元素，按当前素材挑选，不要求所有作品出现同一种道具。

**代表段检查**：一眼能否读出环境与观看顺序；地标是否可辨；至少两个不同的空间层是否有真实遮挡/视差；一个对象的动作是否改变下一个状态；实拍进入是否由前述构图自然引出；手机缩小后标题与主物是否仍清晰。缺项时先改峰值构图和资产，不能用更多贴纸补救。

## 素材先拆成能动的资产

重要场景先在真实底图上完成一个静态峰值构图，再准备可动图层。每个主要插画/合成单元在现有资产表增加：

`asset_id / role / file或组件 / 实际尺寸 / 透明边缘 / pivot / 可动部件 / 遮挡关系 / 关联effect_id / 可用状态`。

- 环境、远景、主体、前景遮挡、文字、辅助粒子分开；仅绘制本场需要的部件，不强制凑固定图层数。
- 载具需车体、车轮或其他实际动作部件；人物卡通需头、身体及本次使用的肢体/表情；纸张需纸面、边缘/遮罩、背面或折痕的实际实现。
- 用矢量/程序图形制作时，轮廓、比例、细节、材质要足够支撑最终画面；大面积地标不能用几何占位轮廓直接充当完成美术。
- 需要丰富纹理或插画而现有工具不足时，使用可用的图像生成或授权素材流程，随后切层、清理透明边缘并进入工程。不能只把生成提示词列入交付。
- 切层照片先评估补洞。视差时露出原图没有的区域，要实际修补并标为编辑处理；无法可靠补足则缩小位移。
- 检查 alpha 黑/白边、透明外边距、分辨率、阴影方向和缩放质量。栅格文字与背景烘焙在一起时，不能宣称文字可独立编辑。
- 再利用用户素材和可用工具，避免把临时截图、整幅预览稿或没有授权的画面当成正式工程资产。

## 动作设计必须说明因果

每个主效果写成“什么触发 → 谁运动 → 接触/变化 → 什么结果可见 → 如何接下一镜”。例如：行进符号到达节点，节点展开为照片，照片边界扩展到实拍；不能只写“加一个可爱转场”。

关键动作分为：预备、主动作、接触/峰值、回弹/余动、稳定阅读、退出/接镜。并非每次都要有夸张预备；实拍的真实动作可以承担预备。为每个阶段填确切帧、位置、scale、rotation、opacity、mask、pivot 和曲线。多个属性共用一个触发事件，各自有语义作用。

大动作集中在变化处，停留期可以有轻微环境循环。稳定阅读不等于全部冻结，也不要求所有层一直动。高幅动画与高信息文字错峰，不靠持续抖动制造忙碌。

## 动作配方：输入、步骤与验收

下列时长/帧数是原创调参起点，按最终 fps、节奏和阅读实测修改，不能冒称参考实测参数。

### A. 分层主题舞台与穿景交接

**输入**：本片地貌/建筑/食物/人物等独立资产、首个真实镜头、一个能成为遮挡面的物件。

**动作**：远景先立住；主体按前后关系进入，前景晚半拍越过主体；文字在图形完成处成形。交接用前景经过镜头、窗体连续扩大或同轮廓匹配，首个实拍有同位置/方向的锚点。远近层位移幅度与视差不同，不能一键把整幅图推近。

**工程**：每层独立 pivot、z-order、关键帧和有效区间；遮罩覆盖到画幅外侧，交接前后有同一坐标转换。窗口内照片与正片同源时，保留对象定位与裁切映射。

**检查**：主体没有浮在错误层级；标题完成后能读；接镜无黑边、缩放跳变和双份角标。首镜交接提供新信息而不是又播一次片头。

### B. 路径旅行、载具与节点反馈

**输入**：原创路线/示意场景、行进主体、节点与节点内容。

**动作**：主体沿路径加减速移动，转弯按切线改变朝向；可动部件或身体随移动变化。靠近节点先减速，接触后节点给一次状态反馈，结果文字再出现。路线绘制、主体位置、节点状态由同一进度驱动。

**工程**：路径按弧长采样，不能把控制点编号当匀速距离；车轮转角可用实际累计距离除半径，缩放后单位保持一致。路径朝向和美术默认朝向之间记录偏移角。

**检查**：主体不横着走、不在节点瞬移；转角不突然翻转；标签不会抢在到达之前报完成。示意路线明确其性质，不伪造真实道路或行程。

### C. 人物/物件剪贴出场与弹性动作

**输入**：清楚的真实帧、真实 mask 或原创角色分层、说明身份的文字。

**动作**：实拍动作给停点；主体从画面中分离，局部背景降低信息；轮廓、身份词和辅助短语错峰。角色可做一次倾斜、点头或肢体摆动，随后稳定；回实拍时接原动作的后续。

**工程**：描边来自 alpha 轮廓而非矩形；头、身体和卡片的 pivot 分开；持物或站立接触点保持。需要连动时用父子变换，避免整体漂浮和脚底滑动。

**检查**：边缘干净；身份描述有依据；图形没有把正常表情变成恶意反应。无可用人物时改做真实物件/地标，明确是物件动画。

### D. 手绘描线、涂鸦生长与现场互动

**输入**：需要解释的主体轮廓/动作、少量原创路径或可动表情。

**动作**：线条随注意方向生长，箭头尖端落到实际目标；火花、汗滴或表情经历出现、变化、收尾。主体移动时使用跟踪或足够的关键帧；被前景挡住时图形也有合理遮挡。

**工程**：路径用长度进度控制揭示；缩放、裁切与跟踪坐标统一。风格需要逐帧线条时设计少量轮廓状态，以锁定 fps 的明确帧周期切换，不能每次渲染随机抖。

**检查**：线不是突然全亮；箭头没有漂离主体；循环强度不妨碍表情和阅读；连续变化区间逐帧看。

### E. 撕纸、折叠、贴合与大物件擦镜

**输入**：有美术细节的纸边/布景/物件、前后镜头、遮罩与背面/阴影。

**动作**：边缘揭开或物件进入，遮挡面积连续变化；纸面与阴影跟随折叠方向；接镜在遮挡成立处完成，物件移出后落稳。前景速度与下一镜方向有关，不把转场当独立的随机特效。

**工程**：实际 mask/clip-path 或引擎等效能力；纸面、背面、边缘和阴影分开。无需真正三维时用明确的二维折页，准确描述能力。

**检查**：交叠覆盖完整；新镜不提前穿帮；半透明暗边、锯齿和旧字幕残留已处理；交接后主体位置可辨。

### F. 物件匹配与视觉错觉合成

**输入**：轮廓、朝向或动作可匹配的两个真实片段，以及合成所需遮罩/跟踪。

**动作**：先建立观众能识别的物件；用尺寸/位置/方向匹配切镜，或让前景经过遮住替换。画中画要贴合真实表面，镜头运动时随表面透视变化。必要时保留反光、遮挡和颗粒的一致性。

**工程**：明确匹配帧、裁切、角点或平面跟踪、前景 mask；二维平面贴合与立体重建分开。若依赖实拍巧合而当前素材没有，重新选择匹配点，不用平淡叠化冒称完成。

**检查**：视差、曝光、运动与边缘没有明显跳变；合成设计不作为真实旅行事件证据；不照抄画面中的品牌播放器或识别性标志。

### G. 文字有动作而不只淡入

**输入**：一句承担明确语义的短文案、字形布局、与它发生关系的图形。

**动作**：可按语义逐字落位、沿物件边缘展开、受一次碰撞挤压回弹、被遮挡后露出，或由零散字块拼合。动完后稳住供阅读；读完再被下一动作带走。

**工程**：每字布局与动画分开，字距、基线和中文断行稳定；字块 pivot、遮罩和形变可重建。只能做 scale 时不要把它描述成真实字形变形。

**检查**：字形不糊、描边不挤满字腔；动画不改变词意；同一句不因剪镜重复弹入；不能把普通对白全部做成运动标题。

## 从参考行为到本片实现

需要贴近具体效果时，先分清该镜头依赖实拍动作、剪辑、插画、分割、跟踪、遮罩还是三维；不要用同一个“弹入”近似所有机制。对实际可见的动作，逐项对照：构图占比、层级、进入方向、运动路径、加减速、形变、前后遮挡、文字出现次序、稳定时长、接镜及声音关系。保留可迁移的动作关系，按本片重做人物、插画、文案与视觉识别。

多种方向并行时先按功能组织：生活观察的接镜、主题舞台、人物反馈、章节转场分别选择适用机制。短片不拼贴几支长片的完整开头，也不机械叠加所有配方。

效果记录沿用 cue-sheet / edit-decisions，增加需要的字段：

```yaml
effect_id: FX_scene_01
trigger: 本片中实际成立的事件
frame_space: local # global_start 单列，所有范围为半开区间
fps: 30
global_start: 0
range: [0, 90]
asset_ids: [] # 实做时填写已存在且可用的本片资产
layers: [] # 实做时填写父子关系、z、pivot、mask、坐标空间
phases: [] # 每段填写帧范围、数值状态和插值
visual_peak_frame: null
sound_cue_id: null
implementation: null # 组件/文件/工程节点，完成时不能留空
status: planned # planned / implemented / rendered / reviewed，状态须有相应证据
```

设计字段未填时仍是计划；源码有组件只是 implemented；必须在合成、镜头运动与声音共同存在的渲染段中检查，才能进入 reviewed。不要创建与主时间线分离的第二套手工帧号。

## 引擎无关的确定性动作

从当前全局帧计算本效果局部帧，区间统一 `[start,end)`，实际 fps 来自 composition。用引擎文档中的能力实现等效行为，不凭空写 API。以下仅为数学表达：

```text
u = clamp((localFrame - startFrame) / durationFrames, 0, 1)
easeOutCubic(u) = 1 - (1 - u)^3
point = pathAtArcLength(path, easedProgress * totalLength)
heading = atan2(tangent.y, tangent.x) + artworkHeadingOffset
wheelRotation = distanceTravelled / wheelRadius
```

独立的变换节点分别承担场景定位、对象移动、回弹和局部部件运动，避免多个动画覆盖同一个 transform。空间单位、parent transform、crop 和 mask 使用同一坐标约定。弹簧和循环须可由帧直接求值，使用随机量时固定种子；不依赖系统时间、播放次数、mount 后计时或上一帧积累。

声音 cue 对齐可见接触/完成帧，考虑音频文件头部静音和瞬态 offset。不能把文件起点等同声音峰值；音乐、拟音、原声、效果声的关系必须正常速度试听。自制简单音色只能算真实完成的设计声，不能因程序生成就宣称达到真实乐器或商业配乐质感。

## 八秒原创动作验证示例

前提：已有授权景物照片、原创路径与分层行进物件；30fps，共 240 帧。本例验证因果和图层关系，不代表任何参考的时间测量。

| 局部帧 | 可见动作 | 工程核查 |
|---|---|---|
| `[0,24)` | 环境已可见，远景与前景错峰立起 | 透明边缘、z 与不同运动幅度 |
| `[24,72)` | 行进主体沿路径移动，可动部件连动 | 弧长、朝向、接触点与循环周期 |
| `[72,90)` | 到达节点，节点受力回弹，结果显现 | 接触帧唯一，音点考虑瞬态 offset |
| `[90,138)` | 标题按语义落位，图形退到辅助层 | 字形基线、可读停留和注意中心 |
| `[138,180)` | 原创前景物件越过画面，揭开本片照片 | 遮罩覆盖、同源坐标与交接方向 |
| `[180,240)` | 实拍/照片主体接管，轻微镜内运动 | 不退回固定卡片；保留景观与细节 |

先以实际素材把此类动作链渲染成带声音样段；若素材不支持则设计另一条有相同复杂度的动作链。不能只画联系表就宣布样段通过。

## 动画验收与常见替代失败

- **插画**：有本片专属的实际资产，轮廓和细节在最终观看尺寸成立；静态角标不是完整插画场景。
- **动作**：能说明至少一个“动作导致下一状态”的过程；只有换图、缩放、花字出现时不能判为完成复合效果。
- **层次**：有实际需要的前后遮挡、部件动作或路径变化；颜色分组和多图层本身不是空间关系。
- **节奏**：每个强调后有可读状态；重复使用同一镜头结构时检查动机，不能靠换照片就算新的效果机制。
- **连续性**：抽查起始、峰值、稳定和退出，复杂遮罩/形变/跟踪区间逐帧；低频抽帧只能评价构图，不能证明动画质量。
- **寻址**：从中段 seek、倒序 seek 与从头播放，对同一帧得到相同图形、媒体映射和声音时序。
- **声音**：正常速度带声播放后才能评审冲击、喜剧停顿与音乐质感；响度达标不代表好听，音点数量不代表配合。
- **验收结论**：工程技术通过和视觉效果达标分别报告；未渲染、未听或未看的范围明确保留状态。

## 精确抽帧工具

需要检查短动画、跟踪或遮罩时，使用随包的 `scripts/motion_contact_sheet.py`。依赖 Python 3、FFmpeg 和 FFprobe；不要求额外 Python 包。对恒定帧率文件从头解码，以真实帧序号选取 `[start,end)`；保留全尺寸 PNG、缩略联系表和单元格到源帧的 `frames.json` 映射。

```bash
python3 scripts/motion_contact_sheet.py /absolute/path/to/preview.mp4 \
  --start-frame 90 --end-frame 120 \
  --output /absolute/path/to/new-review-directory
```

输出目录必须不存在；每批最多 180 帧，长区间分批。默认 step=1，逐帧提取；`--step` 大于 1 仅为稀疏采样。联系表便于发现问题，边缘质量仍要打开全尺寸帧。变帧率先把单独副本规范为 CFR，并保留原始映射，不能拿转换后的帧号冒充源帧。

工具只产生抽帧证据，不自动给视觉质量评分；记录初始状态为未审阅、声音未审阅。抽帧成功后仍需实际看图和正常速度带声播放，不能把工具成功等同验收通过。
