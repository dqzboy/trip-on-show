# 效果研究、证据与实现边界

## 三种证据分开

- **直接观察**：实际看到的事件、构图、图层前后关系、运动、遮挡、文字出现与退出；实际听到后才记录音乐、原声、拟音和音点关系。
- **制作推断**：根据画面推测可能使用的切层、遮罩、跟踪、路径、插值或合成方式。仅看输出无法证明原工程、软件、插件和参数，不把推测写成已知事实。
- **本片设计**：为当前素材制作的原创图形、时序、动画曲线、声音与工程实现。参数来自本片测试，不冒称外部作品的实测标准。

公开简介和文章能帮助判断主题与结构，不能据此声称已观看或测量镜头。静态截图可以判断构图，不能证明运动曲线、跟踪稳定或声音品质。

## 可访问片段的拆解方法

在当前分析中先确认媒体确实可播放、画面已解码、时间位置有效。进度条时间变化但画面还在缓冲时，不把旧画面当成新位置。对关键动作查看开始、主动作、接触/峰值、稳定、退出及接镜；必要时逐帧检查。

观察重点：实拍承担什么、图形补充什么、两者如何相互作用；转场由何种物件或动作驱动；花字何时出现，是否先有事件；音点是否落在可见接触或完成上。长片抽段与全片观看分开报告；不能从一个开头推断所有段落，也不把缩略图当完整动态证据。

读取 [animation-playbook.md](animation-playbook.md) 把行为转成可执行资产和工程要求。素材、画幅或时长不同，保留机制并重新构图，不把长片比例或全部包装机械拼进短片。

## 可复用结论的形态

沉淀为“适用素材 → 触发事件 → 分层资产 → 动作阶段 → 路径/遮罩/跟踪 → 文字与声音关系 → 接镜 → 验收”的方法。写清能力依赖、不能替代它的简化做法及适用边界。

现有导演文件的效果表记录本片效果 ID、观察覆盖、可迁移规则、本片时间范围与实现状态。无法访问的片段留待核验，不编造对应关系；用户要精确行为对照而关键动作不可见时，说明该项尚未核验，先实现有证据支持的部分。

## 从观察到完成

文字配方不是素材，资产清单不是已制作插画，动画代码不是已通过画面。高完成度必须由真实素材上的峰值构图、带声音样段及最终工程证明。分别标记计划、实现、已渲染和已检查。

不把现成的台标、角色形象、配乐、声音、完整构图和识别性包装直接作为本片资产；复用可迁移的动作逻辑并重新设计具体表达。实际使用的音乐、字体、素材仍按其许可保留必要记录。
