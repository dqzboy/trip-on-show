# 质量红线与交付自检

所有制作任务的统一闸门：**开工前**用本文件的 design-spec 模板锁定设计，**交付前**用禁止清单与自检流程验收。本文件只收硬性红线（违反任意一条即退回重做，不交付），详细制作方法见文末索引的各文件。

原则：质量检查是制作者的工作，不是用户的工作。用户只做风格裁决，不承担找 bug 的 QA 工作。

## 一、开工前必锁 design-spec

复制到项目的 `design-spec.md`，填完才能开工；任何一项留空即视为未开工：

```yaml
# design-spec.md —— 本片设计锁定
format: 1080x1920        # 画幅：必须先经用户确认，不得默认
fps: 30
palette:                 # 四色锁定，从目的地图谱取色，填实际色值
  base: "#??????"        # 底色：暖、明度高，禁灰蒙低饱和
  primary: "#??????"     # 主色：高饱和（朱砂/海蓝/苔绿等）
  accent: "#??????"      # 点缀色
  stroke: "#??????"      # 描边色
typography:
  dialogue: {}           # 对白字幕：字号/字重/描边/安全区
  huazi: {}              # 花字：全片只有这一套写法，禁多种混用
containers: []           # 花字容器（撕纸板/贴纸带/印章框/笔刷带），全片统一
characters: []           # Q 版角色（仅限舞台画面）+ 代表色
narrator: {}             # 旁白：音色 ID（含引擎版本）/语气/语速
music: {}                # 音乐动机与曲库分类
corner: {}               # 角标样式与固定位置
```

## 二、美术方向预设（起点色板，按本片调整后锁定）

| 方向 | 适用目的地 | base 底色 | primary 主色 | accent 点缀 | stroke 描边 |
|---|---|---|---|---|---|
| 砂岩暖庙 | 古建、古城、北方人文 | `#E8B356` 暖赭 | `#C9401C` 朱砂 | `#1E6B5C` 青绿 | `#3B2A1E` 深褐 |
| 海风蓝白 | 海边、清新、夏日 | `#FFF6E8` 米白 | `#1D6FA5` 海蓝 | `#E86A5C` 珊瑚 | `#173F5F` 深海蓝 |
| 山野青绿 | 山野、徒步、自然 | `#E9E4C9` 浅竹 | `#4A7A3C` 苔绿 | `#D96C2C` 柿橙 | `#24402B` 墨绿 |

红线：灰蒙、发闷的低饱和底（类似 `#D8CDB8` 的脏米色）不得作舞台底色；色值选定后写入 design-spec，不允许逐镜漂移。

## 三、禁止上屏清单（硬性，任一条即退回）

**舞台画面（片头/章节牌/地图页/结算页/落版）**
1. 黑底或大面积纯色托小卡、「单卡居中 + 大面积空白」
2. 首帧空场景：无主体轮廓、无母题装饰；30 秒以内短片主体揭示超过约 1.5 秒
3. 主体占画面高度不足 1/2，竖向空间被空天空/空底浪费
4. 舞台画面四角与边缘无任何母题装饰
5. 灰蒙色板当舞台底色；色板逐镜漂移

**正片包装**
6. 裸照片或裸视频连续超过约 10 秒且无任何视觉系统元素（角标/节点/姓名签/花字容器）
7. 花字裸字直接压照片（无撕纸板/贴纸带/印章框等容器）；同一部片出现两种以上花字写法
8. 黑场淡入淡出充当转场（素材本身为夜景除外）
9. 花字遮挡人脸、食物或关键主体

**Q 版角色**
10. 出现在实拍照片或视频正片上（仅限舞台画面）
11. 正脸无五官（无点状眼 + 嘴）；整头同色深色剪影；单腿或无手臂；帽檐盖脸
12. 「背影 + 正脸」拼贴（背包画在胸前）；图腾、保龄球瓶或图标式轮廓
13. 剪影测试失败：填纯黑后看不出大头小身的可爱小人

**文化物件与插画**
14. 文化实体拟人化（石狮笑脸、建筑加表情）；拟人表情只允许给天气等装饰小物
15. 文化物件画成不可辨认形态（兔耳雪人式团子）；缺主特征仍上屏
16. 通用 emoji 拼贴冒充原创插画；大面积几何占位轮廓充当地标美术

**声音**
17. 每层机械撒同一提示音；音乐全程顶满无留白；旁白音色中途更换
18. 声音与画面明显错位（音点不在动作完成帧）

## 四、交付前自检流程（必须实际执行，并写入 qa-report）

1. 用 `scripts/motion_contact_sheet.py` 抽帧：首帧、每个主体/标题完成帧、每次交接前后、落版，逐帧对照禁止清单逐项打勾。
2. 正常速度**带声**完整播放一次，检查声画同步、对白可懂、音乐不顶满。
3. 手机尺寸或等比缩小预览，检查花字与角标可读、无平台遮挡。
4. design-spec 逐项核对：色板、花字写法、容器、角标是否与锁定一致。
5. qa-report 每项只写「通过 / 需修正 / 未检查」；未检查项必须列出，不允许没看就写通过。
6. **全部硬性项通过才向用户交付**；不通过先修再交，不附带「请帮忙看看哪里有问题」。
